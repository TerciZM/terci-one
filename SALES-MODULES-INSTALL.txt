TERCI ONE — SALES & PURCHASES MODULES UPDATE

INSTALL
1. Extract this ZIP into the root of the Terci One repository, preserving its folders. Allow the included files to replace matching files.
2. In Cloudflare D1, run sales-modules-migration.sql against the app database. It is safe to rerun and adds the Recurring Invoices, Credit Notes, Vendors and Expenses tables. It expects the existing customers, items and invoices tables.
3. Commit and deploy through Cloudflare Pages.

INCLUDED
- Sales modules: recurring invoice profiles and manual invoice generation, Payments Received register, issued credit notes and printable credit note view.
- Purchases navigation with Vendors and Expenses nested under it.
- Vendor create, edit, search, status filtering, addresses, contact persons, payment details, reporting tags and remarks.
- Expense create, edit, search, pagination, vendor/customer association, account category, tax, paid-through method and billable flag.

LIMITS
- Recurring invoice generation is user-triggered from its profile list; unattended generation needs a scheduled job.
- Receipt file uploads and automated receipt extraction are not included because persistent file storage is not configured in this app.
- Vendor payables and unused credits display zero until supplier bills and vendor credits are added.
